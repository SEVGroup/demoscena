# Dem4 build notes

Three new monochrome scenes with strong screen-space object motion. Silent, 96 seconds, one native Apple Silicon executable. Deployment target macOS 13+.

Controls: left/up previous scene; right/down next scene; F / А fullscreen; Esc or Cmd+Q quit.

The build script checks the executable against 65,536 bytes. Verify playback on target hardware and review current event rules before competition submission.
