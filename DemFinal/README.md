# DemFinal

A 45-second waves-only visual study based on Dem0's fourth scene, with the ambient soundtrack from Dem2.

The waves emerge from black during the first 15 seconds, reach full brightness, and hold for 10 seconds. They then gently dim and brighten again before fading completely to black during the final 7.5 seconds. The Dem2 ambient sound follows the same 45-second run and fades out with the picture.

Build with `source/build.sh`, then run `DemFinal` or `Launch.command`. The build script checks the 65,536-byte executable limit. Source files are in `source/`.

Controls: F (including Russian layout А) toggles fullscreen; Esc or Cmd+Q quits.

Live FPS and GPU-frame-share estimates are shown in the upper-right corner. GPU % is this demo's Metal execution time divided by the frame duration, not total system GPU utilization.
