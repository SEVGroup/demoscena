# Dem5 build notes

Three-scene, silent color intro with actively moving objects. Runtime 96 seconds. Apple Silicon arm64, macOS 13+.

Controls: left/up previous scene; right/down next scene; F / А fullscreen; Esc or Cmd+Q quit. Single executable, no external assets.

The build script checks the executable against 65,536 bytes. Verify playback on target hardware and review current event rules before competition submission.
